# Bookify

**Bookify** is a sample .NET 8 application that implements **Pragmatic Clean Architecture (PCA)** combined with **Domain-Driven Design (DDD)** principles.

- Layered architecture:
  - Domain
  - Application
  - Infrastructure
  - Presentation
- CQRS with MediatR
- Validation with FluentValidation
- Persistence with Entity Framework Core
- Authentication with Keycloak (JWT)
- Structured logging with Serilog
- Integration and architecture tests included
